# Engineering Standards

## General Principles

- Prefer simple and maintainable solutions.
- Follow SOLID principles where applicable.
- Favor explicit dependencies.
- Define clear module boundaries.
- Document architectural decisions.
- Protect sensitive information.
- Require automated tests for critical behavior.

## Architecture

- Respect bounded contexts.
- Avoid unnecessary coupling.
- Define explicit integration contracts.
- Prefer backward-compatible API changes.

## Quality

- Automated testing is mandatory.
- CI validation must pass before merging.
- Security must be considered during design.
